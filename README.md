# SmartOffice

Proiect de retea pentru un birou inteligent, realizat in Cisco Packet Tracer. Include proiectarea topologiei, segmentarea pe VLAN-uri, routing intre retele, servicii de baza (DHCP/NAT) si validare prin teste de conectivitate.

**Descriere scurta:** un scenariu complet de retea office care arata cum se construieste si se configureaza o infrastructura functionala pentru un birou modern.

**La ce ne ajuta:** ofera un exemplu practic pentru invatare, laborator sau documentare, si poate fi folosit ca punct de plecare pentru proiecte similare.

## Continut
- `Proiect.pkt` - scenariul si topologia in Packet Tracer.
- `smartoffice.pdf` - documentatia proiectului.

## Utilizare
1. Deschide `Proiect.pkt` in Cisco Packet Tracer.
2. Consulta `smartoffice.pdf` pentru descriere si instructiuni.
